# Data-Science-Projects
> "A collection of end-to-end Data Science projects demonstrating data analysis, visualization, machine learning modeling, and API deployment. Each project includes datasets, notebooks, scripts, and reports for hands-on learning and real-world applications."

## Projects
- **Financial_Transaction_Fraud_Detection** – Detect and predict fraudulent financial transactions using Python, ML, FastAPI, and dashboards.

- **Bengaluru Smart City Traffic Analysis** – Analyze and predict traffic volume, congestion level, and average speed across Bengaluru’s smart city network using Python, Machine Learning models, Flask, and interactive dashboards for real-time traffic monitoring and urban mobility insights.

- **Weather Impact Prediction And Analysis** – Analyze and predict key weather parameters using Python, ML models, Flask, and Power BI dashboards for real-time forecasting and environmental insights.
